# 📊 Exploratory Data Analysis (EDA) Project

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on a sales dataset to understand data patterns, identify trends, and generate business insights through statistical analysis and visualizations.

## 🎯 Objectives
- Clean and preprocess the dataset
- Handle missing values and duplicates
- Analyze sales performance
- Create visualizations for better understanding
- Extract meaningful business insights

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📈 Analysis Performed
- Data Cleaning
- Descriptive Statistics
- Correlation Analysis
- Sales Trend Analysis
- Category-wise Performance Analysis
- Data Visualization

## 🔍 Key Insights
- Identified top-performing products and categories
- Analyzed sales trends over time
- Compared regional performance
- Found relationships between key variables
